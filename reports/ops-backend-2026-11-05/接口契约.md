# 运营后台（客户 / 充值 / 聚合支付）接口契约

> 2026-11-05 定稿。前后端、测试都以此为准；修改契约必须先改本文件。
> 所有权：`server/payment-aggregator.js`（聚合支付）、`server/customers.js`（客户）、`server/recharge-admin.js` + `server/recharge-automation.js`（充值后台）、`src/components/admin/AdminCustomers.vue|AdminRecharge.vue|AdminPayment.vue`（前端）。
> 公共文件 `server/index.js`、`server/payments.js`、`server/credits.js`、`server/rbac.js`、`src/api.js`、`src/components/admin/AdminConsole.vue` 由 Lead 统一接线，队友不要动。

## 0. 通用约定

- 所有 `/api/admin/*` 走 `requireLogin` + `requirePerm`，失败返回 `400 {error}` 或 `403 {error, code:"FORBIDDEN"}`。
- 金额单位：接口对外一律「元」，保留 2 位小数；算力是整数点。
- 时间：服务端存毫秒时间戳；前端自行格式化。
- 审计：写操作必须 `audit.record("admin.action", {action, ...}, ctx)`，action 形如 `customer.profile.update` / `customer.credits.adjust` / `recharge.order.manual_paid` / `recharge.order.refund` / `recharge.plans.save` / `payment.channel.save`。
- 敏感信息（支付密钥）只写不读：任何响应都不得包含 `key` / `appsecret` 明文，只回 `keySet: true/false`。

## 1. 客户中心

### GET `/api/admin/customers?keyword=&status=&level=&page=1&pageSize=20`
返回 `{ rows, total, page, pageSize }`，按 `lastPaidAt` 倒序（无充值记录排后面）。

`row`：
```js
{
  id, username, nickname, email, phone, status, deptId, deptName, roleNames,
  realName, company, wechat, level, levelLabel, tags: [], source, remark, region,
  balance,              // 当前算力
  totalPaid,            // 累计实付金额（paid 订单 price 之和）
  refundAmount,         // 累计退款金额
  totalSpent,           // 累计消耗算力（reserve 流水绝对值求和）
  orderCount,           // 订单数（含 pending/cancelled）
  paidOrderCount,
  lastPaidAt,           // 最近一次支付时间戳，无则 null
  createdAt, lastLoginAt
}
```
权限：`admin:customer:view`。数据范围：复用 admin.js 的 dataScope 规则（all/dept/self/custom）。

### GET `/api/admin/customers/meta`
返回 `{ levels: [{value,label}], sources: [...] }`（等级：normal 普通客户 / vip VIP / svip SVIP / agent 代理商）。

### GET `/api/admin/customers/:id`
返回 `{ customer: {...row, orders: [订单], records: [最近 50 条算力流水], stats: {totalPaid, refundAmount, totalSpent, balance, orderCount} }, profile: {...} }`。
订单字段与第 2 节一致，`records` 直接用 `credits.records(userId,{limit:50})`。

### PUT `/api/admin/customers/:id`
body `{ realName, company, wechat, level, tags, source, remark, region }`；只允许改档案，不改账号密码/角色。
返回 `{ ok: true, customer }`。权限 `admin:customer:edit`。

### POST `/api/admin/customers/:id/adjust`
body `{ amount: 整数（正负都可）, reason }`；走 `credits.adjust()`。
返回 `{ ok: true, balance, delta }`。权限 `admin:customer:edit`。

## 2. 充值中心（含自动管理）

### GET `/api/admin/recharge/orders?status=&userId=&keyword=&from=&to=&page=1&pageSize=20`
返回 `{ rows, total, page, pageSize, summary: { amount, count, pending, paid, refunded } }`。
`from/to` 是毫秒时间戳（按 `createdAt` 过滤）。`keyword` 匹配订单号 / 用户名 / 昵称。

`order`：
```js
{ id, userId, username, nickname, planId, credits, bonus, total, price,
  status,        // pending | paid | cancelled | expired | refunded
  channel,       // wechat | alipay | aggregator | manual | sandbox | ""
  payMethod, createdAt, paidAt, expiredAt, refund, notes }
```

### GET `/api/admin/recharge/stats?days=30`
```js
{ today: {amount,count}, yesterday: {amount,count},
  range: {amount,count,refundAmount,paidUsers},
  byChannel: [{channel,amount,count}],
  byStatus: [{status,count}],
  trend: [{date:"2026-11-05",amount,count}],   // 连续 days 天，补零
  topCustomers: [{userId,nickname,totalPaid,orderCount}] }
```
只统计 `status==="paid"` 的订单金额；`refundAmount` 统计 `refunded`。

### POST `/api/admin/recharge/orders/:id/manual-paid` body `{ reason }`
人工补单：校验订单存在且 pending，调 `credits.markPaid(id,"manual")`，写审计（含 reason）。
返回 `{ ok: true, order, balance }`。权限 `admin:recharge:manage`。已 paid 幂等返回 `{ok:true,already:true}`。

### POST `/api/admin/recharge/orders/:id/sync`
主动查单：仅 pending；调聚合支付 `queryOrder`，真已支付则 `credits.markPaid(id,"aggregator")`。
返回 `{ ok: true, paid: boolean, order?, reason? }`。权限 `admin:recharge:manage`。

### POST `/api/admin/recharge/orders/:id/refund` body `{ reason }`
调 `credits.refundOrder(id,{reason,actor})`；失败（余额不足等）400 返回错误原文。
返回 `{ ok: true, order, balance, deducted }`。权限 `admin:recharge:manage`。

### POST `/api/admin/recharge/orders/:id/note` body `{ note }`
返回 `{ ok: true, order }`。

### GET `/api/admin/recharge/plans` → `{ rows }`（含 total/perUnit）
### PUT `/api/admin/recharge/plans` body `{ rows: [{id,credits,bonus,price,label,hot}] }`
调 `credits.savePlans(rows)`，返回 `{ ok, rows }`。权限 `admin:recharge:manage`。

### GET `/api/admin/recharge/automation`
返回 `{ config: {enabled, expireMinutes, syncAfterSec, syncBatch, updatedAt}, lastReport: {at, expired, synced, paid, errors} | null }`。
### PUT `/api/admin/recharge/automation` body 同 config 字段（部分更新）
`expireMinutes` 5~1440，`syncAfterSec` 30~3600，`syncBatch` 1~100。返回 `{ ok, config }`。
### POST `/api/admin/recharge/automation/run`
立即执行一轮：过期 pending → 查单补单 → 写报告。返回 `{ ok, report }`。权限 `admin:recharge:manage`。

## 3. 聚合支付通道

### 聚合支付模块对外函数（`server/payment-aggregator.js`）
```js
export function loadConfig();                    // env AGG_* > pay-config.json.aggregator
export function saveConfig(patch);               // 深合并写回 pay-config.json，mode 0600；key 传 ""=不改，传 "__CLEAR__"=清除
export function maskedConfig();                  // 不含明文 key，仅 keySet/appsecretSet
export function isConfigured(cfg?);              // provider/gateway/pid/key（或 appid/appsecret）齐全
export function signParams(params, provider);    // 纯函数，返回 {signStr, sign}
export async function createPayment(order, cfg?);// {provider, mode:"redirect"|"qrcode", payUrl, qrCode, tradeNo, raw}
export function verifyNotify({provider, params});// {ok, reason?, outTradeNo, amount(分), tradeState, raw}
export async function queryOrder(outTradeNo, {cfg}={}); // {ok, paid, amount, tradeNo, raw}
export async function testConnection(cfg?);      // {ok, provider, latencyMs, message}
```
协议：
- `epay`：易支付/蓝兔/彩虹易支付通用。下单 `GET {gateway}/submit.php?pid&type=wxpay|alipay&out_trade_no&notify_url&return_url&name&money&sign&sign_type=MD5`；签名 `md5(按 k 升序拼接 k=v&…（排除 sign/sign_type/空值）+ key)` 小写；回调 form 参数验签，`trade_status==="TRADE_SUCCESS"` 为成功，`money` 元→分；回包体必须是纯文本 `success`；查单 `GET {gateway}/api.php?act=order&pid=&key=&out_trade_no=`。
- `xunhupay`：虎皮椒。下单 `POST {gateway}/payment/do.html` form（appid/trade_order_id/total_fee/title/time/notify_url/return_url/nonce_str/hash），`hash=md5(排序 k=v 拼接 + appsecret)`；回调验 `hash`，`status` 为 `OD`/`CD` 视为支付成功；查单 `POST {gateway}/payment/query.html`。
- `custom`：自建聚合。下单 `POST {customCreateUrl}` JSON + `X-Agg-Sign: HMAC-SHA256(rawBody, key)`；回调 JSON `{out_trade_no, amount(分), status:"paid", sign}`，验 HMAC；查单 `POST {customQueryUrl}`。
- 金额一律元转分用 `Math.round(Number(money)*100)`，禁止浮点直接比较。
- 不打印、不回显密钥；请求超时默认 10s（`AbortSignal.timeout`）。

### GET `/api/admin/payment/channels`
```js
{ mode: "aggregator|wechat|alipay|sandbox", sandbox: boolean,
  channels: {
    wechat: { configured, mchIdSet, ... }, alipay: {configured},
    aggregator: { provider, gateway, pid, keySet, appid, appsecretSet, notifyBaseUrl, returnBaseUrl, methods:[], configured }
  }, hint }
```
### PUT `/api/admin/payment/channels` body `{ provider?, aggregator?: {provider,gateway,pid,key,appid,appsecret,notifyBaseUrl,returnBaseUrl,methods} }`
`provider` 用于切换当前生效通道（`aggregator|wechat|alipay|""` 自动）。返回 `{ ok, channels }`。权限 `admin:payment:config`。
### POST `/api/admin/payment/channels/test` body `{ provider? }`
返回 `{ ok, provider, latencyMs, message }`。权限 `admin:payment:config`。
