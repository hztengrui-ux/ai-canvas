A · Aurora 推荐 · 桌面端

极光玻璃 / 玻璃拟态 / 深色优先

深空底色 + 极光渐变环境光 + 玻璃面板。对标 Linear、Figma Dark，是目前国际 SaaS 桌面端的最高审美水位，且最贴合「创作工具」的心智 —— 深色让图片内容跳出来。

  • 气质：专业、克制、贵
  • 动效：极光缓慢漂移、玻璃 hover 发光
  • 代价：浅色模式要重新调一版（不是简单反转）

B · Atelier

画布工作室 / 暖白纸感 / 衬线标题

暖米白 + 炭黑 + 单一国际橙。衬线大标题营造「工作室 / 杂志」的创作氛围，和满大街的冷蓝 admin 立刻拉开差距。辨识度最高、最不像别人的产品。

  • 气质：人文、手作、有温度
  • 动效：硬朗利落，hover 直接触达
  • 代价：衬线标题对中文渲染要求高

C · Momentum

流光灵动 / 纯白大圆角 / 渐变 CTA

纯白底 + 26px 大圆角 + 多层柔影 + 渐变流光按钮。对标 Stripe、Notion，亲和、轻盈、最「鲜活」，浅色下用户的图片素材也最接近真实观感。

  • 气质：亲和、现代、有活力
  • 动效：按钮流光、卡片悬浮、微位移
  • 代价：白底最考验留白纪律，密度高了就俗
怎么选：桌面端 Electron + 图片创作场景，首推 A Aurora（深色让作品图成为主角，专业感最强，国际感最足）； 若用户群偏电商运营、白天长时间使用，选 C Momentum（亮色久用不累）；想要品牌辨识度拉开、有「设计品牌」野心，选 B Atelier。 三个方案的 CSS 变量命名与现有 style.css 一一对应（--bg / --surface / --accent / --radius / --shadow…）， 定稿后只换 token + 补局部动效，业务代码零改动，预计 2–3 天完成全面执行。
