# 跨多多科技 · 视觉规范 v1.0

> 提取自「跨多多 AI 创作台」（`ai-canvas`）的**实现代码**，不是设计稿转述——
> 每个色值、字号、圆角都能在源码里找到出处，所以拿去给别的工具用不会"看起来像但细节不对"。

**配套文件**

| 文件 | 用途 |
|---|---|
| `tokens.css` | 直接 `<link>` 引入，`var(--kk-*)` 取值；含深色主题与常用组合类 |
| `tokens.json` | 给设计工具 / 构建脚本 / 文档系统读的结构化令牌 |
| `kk-tailwind.config.js` | Tailwind 主题扩展（颜色、圆角、阴影、字号） |
| `kk-element-plus.css` | Element Plus 变量覆盖（换掉默认蓝色主色） |
| `kk-antd-theme.js` | Ant Design v5 `ConfigProvider` 的 theme token |
| `swatch.png` | 一页看全的样张（给同事/客户看最快） |
| `swatch.html` | 样张源码，改颜色可再出图 |

## 一、三条设计原则

1. **中性灰打底，墨黑做结构与主文字。** 页面底永远是浅灰（`#ECEFF2`），内容承载在纯白卡片上，标题与数值用墨黑（`#15171E`）。不用整屏彩色。
2. **荧光绿只做"行为色"。** 它代表"这里可以点、这里是当前项"。一个界面里最多出现 2~3 处（主 CTA、当前项、关键状态）。**它不是装饰色**——一旦拿它画分栏背景、卡片描边、图表系列色，整个界面立刻变廉价。
3. **不用蓝色做主色系。** 蓝色会把"科技感"做成"后台管理模板感"。状态色里如果需要"信息"档，用石板灰（`#5A6274`），不要拉回蓝。

## 二、色彩

### 2.1 中性色（底层）

| 令牌 | 色值 | 用途 |
|---|---|---|
| `--kk-bg` | `#ECEFF2` | 页面背景 |
| `--kk-surface` | `#FFFFFF` | 卡片、面板、输入框 |
| `--kk-surface-hover` | `#F5F6F8` | 悬停、内嵌块、禁用底 |
| `--kk-border` | `#E4E7EB` | 1px 分隔线、描边 |
| `--kk-border-strong` | `#D3D8DE` | 虚线框、需要更明确边界时 |

> 深色：`#0C0E14` / `#141721` / `#1B1F2B` / `#262B39` / `#363D4F`

### 2.2 文字层级（四档，不要更多）

| 令牌 | 色值 | 用途 |
|---|---|---|
| `--kk-text` | `#15171E` | 标题、数值、主文字 |
| `--kk-text-2` | `#5A6274` | 正文、次要按钮文字 |
| `--kk-text-3` | `#838CA0` | 说明文字、图标默认色 |
| `--kk-text-4` | `#A6ADBD` | placeholder、禁用、极弱提示 |

> 深色：`#F4F6FC` / `#A3ACC0` / `#7A8398` / `#5C6478`

### 2.3 行为色（墨黑 + 荧光绿）

| 令牌 | 色值 | 用途 | 备注 |
|---|---|---|---|
| `--kk-ink` | `#15171E` | 主按钮底、当前项、深色舞台 | 悬停 `#2B2F37`，按下 `#000` |
| `--kk-lime` | `#D8FA34` | 主 CTA、当前项 | **必须配墨黑文字**，白字对比度不足 |
| `--kk-lime-deep` | `#BCE600` | 荧光绿悬停 | |
| `--kk-lime-ink` | `#181A0C` | 荧光绿底上的字色 | 别用纯黑，会发死 |
| `--kk-accent-grad` | `135°, #EBFF7A → #D8FA34 → #BCE600` | 主 CTA 渐变底 | 用渐变时字色仍是 `#181A0C` |

**绿色谱的另外两档**（"需要绿但不能抢 CTA"的地方）：

| 色值 | 用途 | 说明 |
|---|---|---|
| `#4E9E00` | 白底上的绿色文字 / 图标 / 链接 | 对比度约 4:1，可读 |
| `#86D000` | 图标描边、悬停态 | 不做大面积底色 |

> ⚠️ **最容易犯的错**：把 `#D8FA34` 当文字色放在白底上（几乎看不清），或者拿它铺满整块区域（变成"荧光绿灾难"）。

## 三、字体

- 字体族：`-apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`
- 等宽（文件名、ID）：`ui-monospace, Consolas, monospace`
- 中文字重用 `600 / 700 / 800`，避免 500（中文细体在浅底上发虚）

| 名称 | 字号 / 字重 | 行高 | 用途 |
|---|---|---|---|
| hero | 50px / 800，字距 -1.2px | 1.1 | 登录页、落地页大标题 |
| 页面标题 | 30px / 800，字距 -0.6px | 1.2 | 面板标题 |
| 卡片标题 | 20px / 750 | 1.35 | 卡片、空状态标题 |
| 正文 | 13.5px / 400 | 1.7 | 说明、段落 |
| 标签 | 12.5px / 600 | 1.4 | 表单标签、表格表头 |
| 辅助 | 11.5px / 400 | 1.6 | 提示、页脚 |
| 微标识 | 10.5px / 700，字距 2.4px | 1.2 | `SETUP`、英文小标 |

## 四、圆角 / 阴影 / 间距

**圆角只有四档**（再造第五档会让界面显得随意）：

| 令牌 | 值 | 用途 |
|---|---|---|
| `--kk-radius-sm` | 10px | 小按钮、输入框、标签 |
| `--kk-radius` | 14px | 内嵌卡、提示条 |
| `--kk-radius-lg` | 20px | 主卡片、面板 |
| `--kk-radius-xl` | 28px | 全屏面板、玻璃层 |
| `--kk-radius-pill` | 999px | 模式切换、Chip、状态标签 |

**阴影走"环境光"**，几乎看不到硬边：

```css
--kk-shadow:      0 1px 2px rgba(21,23,30,.04), 0 10px 26px -20px rgba(21,23,30,.35);
--kk-shadow-md:   0 2px 8px rgba(21,23,30,.05), 0 24px 48px -26px rgba(21,23,30,.4);
--kk-shadow-lime: 0 6px 16px -8px rgba(188,230,0,.85);   /* 只给荧光绿按钮 */
```

**间距为 4 的倍数**：`4 / 8 / 12 / 16 / 24 / 32 / 48`。卡片内边距用 16，卡片之间 12，区块之间 24~32。

## 五、组件标准

### 5.1 按钮（三档 + 图标按钮）

| 类型 | 高度 | 圆角 | 内边距 | 底色 / 字色 | 用途 |
|---|---|---|---|---|---|
| 主 CTA | 40~50px | 12~13px | 0 18~20px | 荧光绿 / `#181A0C`，带 `--kk-shadow-lime` | 一屏只放一个 |
| 墨黑按钮 | 40px | 12px | 0 18px | 墨黑 / 白字 | "编为作品组"这类主操作 |
| 次级按钮 | 32px | 10px | 0 13px | 白底 + 1px 描边 / `--kk-text` | 绝大多数操作 |
| 图标按钮 | 30×30 | 8px | — | 透明底 / `--kk-text-3`，悬停 `--kk-surface-hover` | 顶栏工具 |
| 工具条按钮 | 40×40 | 12px | — | 同上，图标 17px，激活为荧光绿底 + 墨黑图标 | 画布左栏 |

状态：`hover` 加深一档 / `disabled` 底变 `--kk-surface-hover`、字变 `--kk-text-4`、**不假装可点**。

### 5.2 胶囊切换（模式 / 分栏）

高 32px、圆角 999、内边距 `0 12px`；当前项 = 墨黑底 + 白字（或荧光绿底 + 墨黑字，二选一，不要混用两种"当前"）。

### 5.3 Chip（标签式动作）

高 28px、圆角 999、1px 描边；选中 = 墨黑底白字；**不要**给 Chip 加阴影。

### 5.4 输入框

高 48px（表单）/ 32px（行内）、圆角 13px（表单）/ 10px（行内）、白底 + 1px `--kk-border`；
聚焦：描边 `--kk-lime-deep` + `0 0 0 4px rgba(216,250,52,.28)` 光晕。

### 5.5 卡片

白底、1px `--kk-border`、圆角 20px、内边距 16px、`--kk-shadow`；
**卡片套卡片时内层去掉阴影**，只用底色区分（`--kk-surface-hover`）。

### 5.6 磨砂玻璃

只在"覆盖在图像或深色之上的浮层"使用（大图预览、对比弹层）：`blur(26~38px) saturate(1.2)` + `--kk-glass` + 1px 高光边 + 圆角 22~28。**浅色平面上不要用玻璃**，没有层次，只会显得糊。

### 5.7 状态角标

18×18 圆形或胶囊，白底/语义色底 + 图标：
完成 ✅ `#2E9E6B`、进行中 `--kk-lime` + 墨黑、失败 `#E0553F`、排队 = 灰字数字。

## 六、图标标准

- **一套线性图标（Element Plus Icons）**，不混面性图标；
- 尺寸只有两档：**15px**（顶栏、按钮内）/ **17px**（画布工具条）；大标题旁最多 20px；
- 颜色规则：默认 `--kk-text-3` → 悬停 `--kk-text` → **激活 = 荧光绿底 + 墨黑图标**（不换图标、不加描边、不放大）；
- 图标与文字间距 6px；图标不要单独承担"危险"语义，危险要有颜色或文案；
- 同一容器内图标尺寸必须一致（这是"看起来专业"最便宜的一条）。

常用语义映射：

| 图标 | 含义 | 图标 | 含义 |
|---|---|---|---|
| `Aim` | 无限画布 / 聚焦 | `Files` | 全自动批量 |
| `Grid` | 批量节点 / 网格 | `Picture` | 图片素材 |
| `MagicStick` | AI 生成 | `Document` | 文档 / 详情页 |
| `Collection` | 素材库 | `Avatar` | 人像 / 模特 |
| `Setting` | 设置 | `Moon` / `Sunny` | 外观 |
| `Download` | 导出 | `Delete` | 删除 |
| `QuestionFilled` | 帮助 | `RefreshLeft` / `RefreshRight` | 撤销 / 重做 |

## 七、深色主题（重要提醒）

本项目的深色主题是历史遗留：`--brand` 仍是蓝紫 `#7C90F6`，与荧光绿语言**不一致**。
`tokens.css` 里已经给出**对齐版**深色令牌，接入新工具请用这一套：

- 底 `#0C0E14` → 面 `#141721` → 悬停 `#1B1F2B` → 描边 `#262B39`；
- 荧光绿提亮为 `#DDFF45`（深底上 `#D8FA34` 会发暗）；
- "墨黑按钮"反转为浅色按钮（`#F4F6FC` 底 + `#15171E` 字）；
- 阴影加重、加不透明度（`rgba(0,0,0,.8)`）。

## 八、移植到其它工具

### 8.1 纯 CSS / 任意框架

```html
<link rel="stylesheet" href="tokens.css" />
<button class="kk-btn kk-btn--primary">开始生成</button>
```

### 8.2 Tailwind

```js
// tailwind.config.js
const kk = require("./kk-tailwind.config.js");
module.exports = { theme: { extend: kk.extend } };
```

### 8.3 Element Plus

```js
// main.js —— 顺序很重要：令牌在前，EP 变量覆盖在后
import "./tokens.css";
import "./kk-element-plus.css";
import "element-plus/dist/index.css";
```

### 8.4 Ant Design v5

```jsx
<ConfigProvider theme={kkAntdTheme}>…</ConfigProvider>
```

### 8.5 只想要颜色（Figma / 其它设计工具）

直接把 `tokens.json` 的 `color` 段导入为调色板；命名保持一致（`bg / surface / text / ink / lime / success / warning / danger`），团队协作时不会各叫各的。

## 九、落地检查清单

- [ ] 一屏之内荧光绿出现 ≤ 3 处，且都在"可点 / 当前 / 关键状态"上
- [ ] 没有蓝色主色；"信息"档用的是石板灰
- [ ] 正文没有小于 11.5px 的字；没有 500 字重的中文
- [ ] 圆角只用 10 / 14 / 20 / 28 / 999
- [ ] 同一容器图标尺寸一致，激活态是"绿底墨黑图标"
- [ ] 主 CTA 只有一种样式；禁用态是灰的，不假装能点
- [ ] 阴影是环境光（无硬边），荧光绿按钮才带 `shadow-lime`
- [ ] 玻璃层只出现在图像/深色之上
